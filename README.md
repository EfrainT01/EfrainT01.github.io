# EfrainT01.github.io
Pagina de prueba para la Clinica Odontologica Sonrisa Perfecta.

## Archivos que no deben subirse

El archivo `docs/.gitignore` evita subir archivos locales o sensibles, como:

- `.env` y otros archivos con variables de entorno.
- `docs/appseting.json` y `appsettings*.json`, porque pueden contener cadenas de conexion y credenciales.
- `node_modules/`, `dist/`, `build/` y `coverage/`.
- Configuraciones del editor (`.vscode/` y `.idea/`) y archivos del sistema.

La cadena de conexion incluida en la configuracion es ficticia y solo sirve para pruebas locales. Nunca agregues contrasenas, claves API o credenciales reales al repositorio.
